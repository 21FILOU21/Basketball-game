01 — Base locale des joueurs NBA

La base utilise un schéma JSON versionné. Les données importées sont sauvegardées dans le navigateur; pour écrire un vrai fichier sur l’ordinateur, utilise « Lier / créer le fichier de base » et autorise l’accès proposé par le navigateur.

La synchronisation automatique nécessite le service Node.js du projet. Si la source refuse l’accès, la catégorie est signalée comme indisponible et la base existante est conservée. L’import CSV/JSON reste disponible en solution de repli.

Aucune synchronisation automatique confirmée. Clique sur « Prise de data » ou lance le service local.
